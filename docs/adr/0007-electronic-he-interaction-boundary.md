# Treat H/E interaction as electronic-backend computation

The fixed optical frontend ends at the first-order modulus, and structured H/E
interaction begins in the electronic backend with explicit stain, scale,
orientation, spatial, and optional branch-feature semantics. This permits
trainable cross-stain modeling while preserving a hard non-trainable optical
boundary; all interaction parameters therefore count toward backend capacity, and
the boundary identity covers stain separation as well as the shared Morlet kernel
contract.
